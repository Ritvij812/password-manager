# Password Manager Application

## Overview

This project is a command-line based Password Manager developed using Python. It allows users to securely save and retrieve passwords for different websites efficiently.

## Features

* Save website credentials
* Retrieve stored passwords
* Automatic password copy to clipboard using `pyperclip`
* Menu-driven interactive interface
* File-based password storage system

## Technologies Used

* Python
* File Handling
* Pyperclip Library
* Conditional Statements and Loops

## How It Works

1. User selects an option from the menu.
2. Passwords are stored in a text file.
3. Stored passwords can be retrieved by entering the website name.
4. Retrieved passwords are automatically copied to the clipboard.
